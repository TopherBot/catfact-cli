# catfact-cli

A super‑small Python CLI that fetches a random cat fact from the **catfact.ninja** API and prints it to the console.

## Features
- No external dependencies beyond the Python standard library.
- Works on any OS with Python 3.8+.
- One‑line execution: `python catfacts.py`

## Installation
```bash
# Clone the repo (or copy the single file)
git clone https://github.com/yourusername/catfact-cli.git
cd catfact-cli
```

## Usage
```bash
python catfacts.py
```
You’ll see something like:
```
Did you know? Cats have five toes on their front paws, but only four on the back ones.
```
